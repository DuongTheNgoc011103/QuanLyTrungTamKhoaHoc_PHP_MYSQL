# 📚 Website Quản Lý Các Khóa Học Của Trung Tâm

## 📝 Giới thiệu
Website được xây dựng nhằm hỗ trợ trung tâm đào tạo quản lý học viên, giảng viên, khóa học, lớp học và lịch học một cách hiệu quả.  
Hệ thống giúp tự động hóa các quy trình quản lý, giảm thiểu sai sót và tiết kiệm thời gian so với phương pháp thủ công.

## ✨ Tính năng nổi bật
- Quản lý học viên (Thêm, sửa, xóa, tìm kiếm, import từ file Excel).
- Quản lý giảng viên (Thêm, sửa, xóa, tìm kiếm).
- Quản lý danh mục khóa học và chi tiết khóa học.
- Quản lý lớp học, ca học, lịch học.
- Quản lý đăng ký khóa học, xác nhận yêu cầu, phân lớp cho học viên.
- Quản lý thi cử (lịch thi, đăng ký thi, nhập điểm, cập nhật điểm).
- Quản lý hóa đơn và thanh toán.
- Phân quyền người dùng (Nhân viên quản lý, Giảng viên).
- Báo cáo và thống kê.

## 🛠️ Công nghệ sử dụng
**Frontend:**
- HTML, CSS, JavaScript
- Bootstrap 5

**Backend:**
- PHP 8.2
- MySQL (phpMyAdmin, XAMPP)

**Khác:**
- PowerDesigner (thiết kế mô hình dữ liệu ERD, DFD, PDM)
